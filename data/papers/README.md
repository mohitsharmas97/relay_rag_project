# Add the research papers here

Put the three PDF files in this directory using these names so the retrieval code can identify the required paper and version:

- `attention_is_all_you_need.pdf` — arXiv 1706.03762 version 7
- `moshi.pdf` — arXiv 2410.00037 version 1
- `dynamic_chunking.pdf` — arXiv 2507.07955 version 2

Alternatively, from the project root run `python scripts/fetch_papers.py` to download these exact versions. The PDF files are not included in this ZIP.
